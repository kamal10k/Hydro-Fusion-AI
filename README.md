# HydroFusion AI – The Digital Chemist

> **An AI-powered water management system for AI and Data-Center Cooling Systems.**

HydroFusion AI analyzes cooling water chemistry and data-center thermal telemetry, predicts mineral scaling risk using a Random Forest Classifier, calculates an optimal freshwater–greywater blending ratio, and provides interactive AI assistance via Google Gemini.

---

## 🌟 Key Capabilities

1. **Scikit-Learn Scaling Risk ML Engine**: Random Forest Classifier evaluating scaling risk (`LOW` vs. `HIGH`) and risk probability percentage based on thermodynamic saturation indexes.
2. **Freshwater–Greywater Blending Optimizer**: Optimization algorithm calculating optimal dilution ratios to minimize municipal freshwater usage while keeping mineral concentrations below scaling thresholds.
3. **Google Gemini AI Assistant ("The Digital Chemist")**: Natural language risk explanations, actionable maintenance recommendations, and interactive AI chatbot.
4. **Agentic AI & n8n Workflow Orchestration**: 6-agent cascade (*Water Monitoring*, *Scaling Risk*, *Optimization*, *Decision*, *Maintenance*, *Alert*) dispatching automated notifications via n8n webhooks on high-risk events.
5. **Interactive What-If Laboratory**: Sandbox environment allowing operators to adjust sliders for TDS, pH, GPU power, and cooling cycles to simulate real-time risk reduction.
6. **Executive Dashboard & Reporting Suite**: Real-time telemetry cards, interactive Chart.js trend lines, historical audit tables with CSV export, and printable executive reports.

## 📊 Telemetry Parameters & Validation Rules

| Group | Parameter | Unit | Valid Range | Purpose |
|---|---|---|---|---|
| **Data Center** | GPU Temperature | °C | 0 - 120 °C | Heat generated by AI workload |
| | GPU Power Load | % | 0 - 100 % | GPU utilization percentage |
| | Ambient Temperature | °C | -20 - 60 °C | Surrounding environmental temperature |
| | Humidity | % | 0 - 100 % | Air humidity level |
| | Water Temperature | °C | 0 - 80 °C | Cooling loop water temperature |
| **Water Quality** | TDS (Total Dissolved Solids) | ppm | 0 - 5000 ppm | Dissolved mineral concentration |
| | pH Level | pH | 0.0 - 14.0 | Water acidity / alkalinity index |
| | Conductivity | µS/cm | 0 - 5000 µS/cm | Dissolved ionic charge conduction |
| **Cooling System**| Cooling Tower Age | years | 0 - 50 years | Tower lifecycle dynamics |
| | Cooling Cycles | count | 1 - 50 | Cycles of concentration |
| | Flow Rate | L/min | 1 - 1000 L/min | Cooling water circulation speed |
| | Daily Water Usage | L/day | 10 - 100,000 | Total daily volume consumption |

## 🛠 Tech Stack

- **Backend**: Python 3.11+, Flask, Flask-CORS, Flask-Bcrypt, PyJWT, SQLite, SQLAlchemy.
- **Machine Learning**: Scikit-Learn (Random Forest Classifier), Pandas, NumPy, Joblib.
- **Generative AI**: Google Gemini API (`google-genai`).
- **Agentic AI**: Multi-agent workflow orchestrator & n8n webhook dispatcher.
- **Frontend**: React 19, Vite, Lucide Icons, Chart.js, React-Chartjs-2, Canvas-Confetti.
- **Deployment**: Docker, Docker Compose, Render ready.

## 🚀 Quick Start Guide

### 1. Backend Setup

```bash
# Navigate to project directory
cd HydroFusion-AI

# Activate virtual environment
backend\venv\Scripts\activate   # Windows
# or
source backend/venv/bin/activate # Linux/macOS

# Install dependencies
pip install -r backend/requirements.txt

# Train Random Forest Model & Seed Sample Data
python -m backend.train_model

# Run Flask Backend Server (Port 5000)
python -m backend.app
```

### 2. Frontend Setup

```bash
# Install node dependencies
npm install

# Start Vite Development Server (Port 5173)
npm run dev

# Or build production static bundle
npm run build
```

### 3. Docker Container Deployment

```bash
# Build and launch complete full-stack container stack
docker-compose up --build
```
